This is a Vite + React frontend for the UI/UX Usability Agent.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The app entry point is `src/main.jsx` and the routed pages live in `src/pages/`.

## Notes

- The frontend talks to the FastAPI backend at `http://127.0.0.1:8001`.
- The backend must be running before planning, generation, evaluation, or preview screens will work.
